                      Hébergement

                      « Bâtiment » sert à créer un filtre par bâtiment sur la page « Hébergement » ET à identifier le bâtiment de chaque UV dans l’onglet « Gérer les infrastructures d’hébergement ». « Chambre » (numéro seul) sert à l’ajout/suppression d’UV ; « UV » est l’identifiant combiné affiché sur la page Hébergement (ex. « 3-12 » → « Bâtiment 3 - Chambre 12 »). « Occupants » doit être une colonne Liste de choix (ou Références multiples) : chaque occupant de l’UV s’affiche alors comme un badge séparé.

                      « Capacité » (colonne numérique) : nécessaire pour utiliser l’onglet « Gérer les infrastructures d’hébergement » ; sur la page Hébergement, si réglée, chaque carte UV prend un fond pastel selon l’occupation — orange si un seul occupant, vert si le nombre d’occupants égale la capacité, rouge s’il la dépasse (le nombre d’occupants est toujours calculé automatiquement à partir du nombre de noms dans la colonne « Occupants »).

                      Nouvelle infrastructure

                      Ajouter des chambres en lot

                      Ajoutez plusieurs chambres d’un même bâtiment en une fois : une infrastructure sera créée pour chaque ligne saisie ci-dessous, avec la même capacité.

                      Une chambre par ligne, par exemple : 101 / 102 / 103.
